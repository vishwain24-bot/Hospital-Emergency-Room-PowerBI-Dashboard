## 📊 Project Overview

This project presents an interactive **Hospital Emergency Room Analytics Dashboard** developed using **Microsoft Excel and Power BI**.

The dashboard transforms hospital emergency room data into meaningful visual insights to help understand patient visits, waiting time, satisfaction, admissions, age groups, and department referrals.

---

## 🎯 Project Objectives

- Analyze emergency room patient visits
- Monitor average patient waiting time
- Analyze patient satisfaction
- Compare admitted and non-admitted patients
- Understand patient distribution by age group
- Analyze department referrals
- Identify trends in patient visits
